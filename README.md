One excuse line in the voice of a hardware wallet that will not sign a transaction at 3 AM, written by a small Node program. The program writes the excuse to `entry.txt` in the output directory, where the make.fun grader reads it:

> It's 3 AM — I've tucked your keys into bed and switched my screen off; I'm not waking them to sign a trade you'll regret by breakfast.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
